# Portfolio evidence

Selected coursework is organized by course. Each Network Security and Network Engineering objective links to its supporting files. PDF copies provide browser viewing; DOCX, PPTX, VSDX, Bash, and text downloads retain useful source formats.

These are reviewed publication copies. Private account and connection identifiers in screenshots are redacted, document metadata and comments are removed, and image metadata is stripped. The design/prototype presentation retains its slides and speaker notes but omits embedded recordings. The vault originals are preserved separately.

The scanner script and its saved report form one evidence package. Designs and planned demonstrations are distinct from completed implementations and observed test results, as described in the objective entries.
